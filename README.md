# 🌦 Weather App

A simple and responsive Weather App built using **Next.js 14 (App Router)**, **Tailwind CSS**, and the **OpenWeatherMap API**.

This app allows users to:
- Search weather by city name
- Fetch current location weather using geolocation
- View temperature, humidity, wind speed, and weather description

## 🧰 Tech Stack

- [Next.js](https://nextjs.org/) (App Router)
- [Tailwind CSS](https://tailwindcss.com/)
- [OpenWeatherMap API](https://openweathermap.org/api)
- HTML5 Geolocation

---

## 🚀 Features

- ✅ City-based weather search
- ✅ Get current weather using GPS
- ✅ Responsive UI with glassmorphism
- ✅ Weather icon and temperature display
- ✅ Built-in loading and error handling
